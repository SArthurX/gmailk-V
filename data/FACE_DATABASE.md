# 人臉資料庫功能說明

## 概述

本系統實現了完整的人臉識別資料庫功能，可以註冊人臉、比對識別並顯示人員資訊。

## 功能特性

### 1. 人臉資料庫模組 (`face_database.h/cpp`)
- ✅ JSON 格式存儲人臉特徵和人員資訊
- ✅ 支援載入、儲存、新增、比對功能
- ✅ 使用餘弦相似度進行人臉比對（閾值 0.4）
- ✅ 自動儲存到檔案：`data/face_database.json`

### 2. 按鈕操作
- **短按（<3秒）**：鎖定當前在中心準星的人臉
  - 人臉框變為紅色
  - 等待 3 秒後自動提取 128 維特徵向量
  - 立即與資料庫進行比對
  
- **長按（>3秒）**：註冊當前鎖定的人臉到資料庫
  - 必須先短按鎖定人臉
  - 等待特徵提取完成後才能註冊
  - 自動分配測試姓名（張三、李四、王五等）

### 3. 顯示功能

#### 視訊畫面顯示
- **匹配成功**：顯示姓名和相似度（綠色文字）
  ```
  ID:123
  張三 (0.85)
  ```
- **無匹配**：顯示 "Unknown"（黃色文字）
- **等待提取**：顯示倒數計時 "Wait 2s"

#### 框線顏色說明
- 🔴 **紅色框**：已鎖定的人臉（正在處理或已識別）
- 🟡 **黃色框**：中心準星位置的人臉（可鎖定）
- 🟢 **綠色框**：穩定追蹤的人臉
- 🔵 **藍色框**：其他追蹤中的人臉

## 使用流程

### 初次使用 - 註冊人臉

1. **啟動程式**
   ```bash
   ./main models/scrfd.cvimodel models/mobilefacenet.param models/mobilefacenet.bin
   ```

2. **定位人臉**
   - 將人臉移動到畫面中心準星位置
   - 確保人臉框變為黃色

3. **鎖定人臉**
   - 短按按鈕（GPIO 21）
   - 人臉框變為紅色
   - 螢幕顯示 "Wait 3s" 倒數計時

4. **等待特徵提取**
   - 保持人臉穩定，等待 3 秒
   - 提取完成後顯示 "Unknown"（因為尚未註冊）

5. **註冊到資料庫**
   - 長按按鈕（>3秒）
   - 系統自動分配姓名並儲存
   - 終端顯示註冊成功訊息：
     ```
     === Face Registered ===
     ✅ Person added to database!
     ID: 1
     Name: 張三
     Track ID: 123
     ======================
     ```

### 日常使用 - 識別人臉

1. **啟動程式**（同上）

2. **等待自動識別**
   - 當已註冊的人臉出現在畫面中
   - 短按按鈕鎖定人臉
   - 等待 3 秒特徵提取
   - 系統自動比對資料庫並顯示結果

3. **查看識別結果**
   - 終端顯示：
     ```
     🎯 Match Found!
        Name: 張三
        Similarity: 0.85
        Person ID: 1
     ```
   - 視訊畫面顯示：姓名 + 相似度

## 資料庫格式

`data/face_database.json` 格式範例：

```json
{
  "version": "1.0",
  "threshold": 0.4,
  "persons": [
    {
      "id": 1,
      "name": "張三",
      "feature": [0.123, -0.456, 0.789, ... (128 個浮點數)]
    },
    {
      "id": 2,
      "name": "李四",
      "feature": [...]
    }
  ]
}
```

## 技術細節

### 相似度閾值
- 預設：0.4
- 範圍：0.0 ~ 1.0
- 數值越高表示要求越嚴格
- 可在程式碼中調整

### 特徵向量
- 維度：128 維浮點數
- 提取模型：MobileFaceNet (NCNN)
- 比對演算法：餘弦相似度

### 測試姓名
目前使用預設姓名陣列：
```cpp
const char* test_names[] = {"張三", "李四", "王五", "趙六", "錢七", "孫八"};
```

後續可以改為：
- 從終端輸入姓名
- 從配置檔讀取
- 透過網頁介面輸入

## 故障排除

### 資料庫初始化失敗
- 確認 `data/` 目錄存在
- 檢查檔案權限
- 查看終端錯誤訊息

### 特徵提取失敗
- 確認 ArcFace 模型路徑正確
- 確保人臉清晰且正面
- 檢查光線是否充足

### 比對不準確
- 調整相似度閾值
- 重新註冊人臉（多個角度）
- 確認模型載入正確
