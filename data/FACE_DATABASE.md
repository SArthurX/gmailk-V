# 人臉資料庫功能說明

## 概述

本系統實現了完整的人臉識別資料庫功能，可以自動識別人臉、註冊並比對顯示人員資訊。

## 功能特性

### 1. 人臉資料庫模組 (`face_database.h/cpp`)
- ✅ JSON 格式存儲人臉特徵和人員資訊
- ✅ 支援載入、儲存、新增、比對功能
- ✅ 使用餘弦相似度進行人臉比對（閾值 0.4）
- ✅ 自動儲存到檔案：`data/face_database.json`
- ✅ 自動創建資料庫目錄（如不存在）

### 2. 自動鎖定與識別
- **自動鎖定**：人臉在中心準星停留 3 秒後自動鎖定
  - 人臉框變為紅色
  - 立即開始提取 128 維特徵向量
  - 自動與資料庫進行比對

### 3. 按鈕操作
- **短按**：重新識別當前鎖定的人臉
  - 清除之前的特徵和匹配結果
  - 重新提取特徵並比對
  
- **長按（>2秒）**：註冊當前鎖定的人臉到資料庫
  - 必須已自動鎖定人臉
  - 必須已完成特徵提取
  - 自動分配測試姓名

### 4. 顯示功能

#### 視訊畫面顯示
- **匹配成功**：顯示姓名和相似度（綠色文字）
  ```
  ID:123
  張三 (0.85)
  ```
- **無匹配**：顯示 "Unknown"（黃色文字）

#### 框線顏色說明
- 🔴 **紅色框**：已鎖定的人臉（正在處理或已識別）
- 🟡 **黃色框**：中心準星位置的人臉（等待自動鎖定）
- 🟢 **綠色框**：穩定追蹤的人臉
- 🔵 **藍色框**：其他追蹤中的人臉

## 使用流程

### 初次使用 - 註冊人臉

1. **啟動程式**
   ```bash
   ./build/main models/scrfd.cvimodel models/mobilefacenet.param models/mobilefacenet.bin
   ```

2. **對準中心**
   - 將人臉移動到畫面中心準星位置
   - 確保人臉框變為黃色

3. **自動鎖定**
   - 保持穩定 3 秒
   - 系統自動鎖定（框變紅色）
   - 立即開始提取特徵

4. **查看結果**
   - 自動比對資料庫
   - 顯示 "Unknown"（因為尚未註冊）
   - 終端顯示：
     ```
     ❌ No match found (similarity below threshold)
     ```

5. **註冊到資料庫**
   - 長按按鈕（>2秒）
   - 系統自動分配姓名並儲存
   - 終端顯示註冊成功訊息：
     ```
     === Face Registered ===
     ✅ Person added to database!
     ID: 1
     Name: eddie
     Track ID: 123
     ======================
     ```

### 日常使用 - 識別人臉

1. **啟動程式**（同上）

2. **自動識別**
   - 當已註冊的人臉出現在中心
   - 保持 3 秒等待自動鎖定
   - 系統自動提取特徵並比對
   - 立即顯示結果

3. **查看識別結果**
   - 終端顯示：
     ```
     🎯 Match Found!
        Name: eddie
        Similarity: 0.85
        Person ID: 1
     ```
   - 視訊畫面顯示：姓名 + 相似度

### 重新識別

如果識別錯誤或想重新嘗試：

1. **短按按鈕**
   - 清除當前特徵和結果
   - 立即重新提取並比對

2. **查看新結果**
   - 終端顯示：
     ```
     === Re-identification Started ===
     Track ID: 123
     🔄 Cleared previous data, re-extracting feature...
     =================================
     ```

## 資料庫格式

`data/face_database.json` 格式範例：

```json
{
  "version": "1.0",
  "threshold": 0.4,
  "persons": [
    {
      "id": 1,
      "name": "A",
      "feature": [0.123, -0.456, 0.789, ... (128 個浮點數)]
    },
    {
      "id": 2,
      "name": "e",
      "feature": [...]
    }
  ]
}
```

## 技術細節

### 自動鎖定機制
- 中心準星範圍：80 像素
- 自動鎖定時間：3 秒
- 特徵提取：立即開始（無額外等待）
- 可在 `src/tdl_handler.cpp` 中調整

### 相似度閾值
- 預設：0.4
- 範圍：0.0 ~ 1.0
- 數值越高表示要求越嚴格
- 可在程式碼中調整

### 特徵向量
- 維度：128 維浮點數
- 提取模型：MobileFaceNet (NCNN)
- 比對演算法：餘弦相似度

### 資料庫檔案
- 格式：JSON
- 位置：`data/face_database.json`
- 自動創建：程式會自動創建不存在的目錄
- 讀取時機：**僅在程式啟動時讀取一次**
- 寫入時機：每次註冊時立即寫入

### 測試姓名
目前使用預設姓名陣列：
```cpp
const char* test_names[] = {"eddie", "nany", "lol", "ccc", "cocoya", "sunba"};
```

後續可以改為：
- 從終端輸入姓名
- 從配置檔讀取
- 透過網頁介面輸入

## 故障排除

### 資料庫初始化失敗
- 確認有寫入權限
- 查看終端錯誤訊息
- 檢查 `data/` 目錄是否可創建

### 自動鎖定不工作
- 確保人臉在中心（黃框）
- 保持穩定 3 秒不移動
- 檢查終端是否有 "Auto-Lock" 訊息

### 特徵提取失敗
- 確認 MobileFaceNet 模型路徑正確
- 確保人臉清晰且正面
- 檢查光線是否充足

### 比對不準確
- 調整相似度閾值
- 重新註冊人臉（多個角度）
- 確認模型載入正確

### 運行中修改資料庫
- **注意**：程式只在啟動時讀取資料庫
- 手動修改 JSON 後需要重新啟動程式
- 建議使用程式的註冊功能而非手動編輯

## 常見問題彙整

**Q: 程式運行中修改 face_database.json 會立即生效嗎？**  
A: **不會**。程式只在啟動時讀取一次資料庫到記憶體中。如果你手動修改了 JSON 檔案，必須重新啟動程式才能讀取到最新的內容。註冊新人臉時，程式會立即將新資料寫入檔案。

**Q: 為什麼改成自動鎖定？**  
A: 簡化操作流程，使用者只需對準中心 3 秒即可自動識別，無需按按鈕。更符合實際使用場景。

**Q: 如果識別錯誤怎麼辦？**  
A: 短按按鈕即可清除結果並重新識別。系統會立即重新提取特徵並比對。
